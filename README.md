I build software in Karachi — and lately I've been building Karachi itself, one district at a time, as the setting of a third-person open-world action game.

TypeScript and Node behind the glass. React and Flutter where people actually touch it. Laravel when the problem deserves battle-tested tooling. PostgreSQL and Redis underneath, Linux all the way down. I've spent enough time doing SOC work that I don't ship anything I can't defend.

### shipping

- **[chaos-protocol](https://github.com/Mustafa-KhanDev/chaos-protocol)** — a third-person open-world action game set in Karachi. The streets I grew up on are the level design.
- **[Cybersecurity-SOC-Portfolio](https://github.com/Mustafa-KhanDev/Cybersecurity-SOC-Portfolio)** — SOC analyst work: detections, log triage, incident write-ups. The blue-team habits that keep everything else I build honest.
- **[nexia](https://github.com/Mustafa-KhanDev/nexia)** — the quiet one. It knows what it did.
- **[project-demo](https://github.com/Mustafa-KhanDev/project-demo)** — the sandbox. Things get tested here before they've earned a real name.
